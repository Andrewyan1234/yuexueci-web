# 粤学词

面向广州中小学生的英语单词音标跟读工具，包含小学广州版和初中沪教牛津版两套词库。

GitHub Pages 地址：

`https://andrewyan1234.github.io/yuexueci/`

## 功能

- 小学三至六年级、初中七至九年级按册和 Unit/Module 浏览
- 单词、短语、英美音标、中文释义和双语例句
- 系统英语语音示范、慢速示范和例句朗读
- 浏览器录音、回放和语音识别跟读评分
- 看词选义、听音选词、音标配对和错题重练
- 本机保存学习进度、连续天数和发音记录

## 运行

在项目目录执行：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

录音功能需要浏览器麦克风权限。`localhost` 和 `https` 环境可以请求麦克风；直接以 `file://` 打开页面时，发音播放可用，但录音功能通常会受限。

## 词库

- `data.js`：教材册别、Unit 元数据和首页跟读内容
- `full-data.js`：初中沪教牛津版完整词表与短语，例句使用词典双语例句
- `primary-data.js`：小学广州版公开词表与小学全词表校订数据，包含短语和例句

当前版本是前端原型，越南/英美音切换、跟读评分依赖浏览器能力。接入微信正式版时，可以把这里的词库和页面结构迁移到原生小程序，并把录音识别替换为微信同声传译或自有 ASR 服务。
